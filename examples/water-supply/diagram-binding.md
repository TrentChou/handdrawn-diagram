# 城市供水系列配图 · 概念配色绑定

画第一张图之前锁定。后续每张图先读本文件；遇到新概念只能追加，不能改已有行。
这一组没有现成的领域字典，颜色按 `references/palette.md` 的「抽象语义」列对应。

## 概念 → 颜色 → 形状

| 概念类别 | 包含组件 | 颜色 slot | 形状 |
|---|---|---|---|
| 水厂（本组主角） | 水厂 | `C.agent` 砖橙 | 总览图里是加粗的大 Box；细节图里展开成同色 `frame()` |
| 净水工序 | 混凝 · 沉淀 · 过滤 · 消毒 | `C.subagent` 焦糖 | Box |
| 储水 | 清水池 | `C.memory` 栗棕 | Box |
| 输送 | 供水管网 | `C.im` 墨青 | Channel |
| 来源 | 水源（水库 · 河流） | `C.external` 墨灰 | Box |
| 用水方 | 用户（住宅 · 学校 · 工厂） | `C.user` 钢蓝 | Box |

## 歧义概念的裁决

- 清水池 → 储水（`C.memory`），不是净水工序。它不改变水质，只是存起来调节供水量。
- 供水管网 → 输送（`C.im`），不是外部依赖。水在里面流动，按「通道 / 传输」的抽象语义归类，形状用 Channel。
